# CARD ALIGN｜卡牌邊框分析與評分小卡

CARD ALIGN 是一款為卡牌收藏者設計的 Android App。

透過卡牌正反面照片、自動邊框偵測與手動校正，協助使用者看懂左右、上下的居中比例，並將分析結果製作成可命名、儲存與分享的收藏小卡。

從確認卡牌邊框，到留下這次收藏的紀錄，整個流程都能在手機上完成。

## 適合哪些人？

- 想確認卡牌居中表現的收藏者。
- 希望在送鑑前整理卡牌邊框紀錄的玩家。
- 喜歡替收藏製作專屬圖片、分享分析結果的使用者。


## 產品特色

### 自動偵測內外框，保留手動微調

自動偵測卡牌外框與內緣，使用者確認位置後，再進行透視校正與比例分析。

若影像沒有清楚的邊界，App 會提供參考框並顯示提示，讓使用者繼續手動對齊。調整過程也能重新偵測、撤銷定位點或還原建議框。



### 正反面邊框分析報告

分別呈現正面與背面的左右、上下邊框比例，並以圖示協助理解偏移方向。比例越接近 **50 : 50**，表示該方向的邊框越均衡。

報告也會顯示 PSA／BGS 的居中預估級別，整體結果取正反面中較低的預估級別。

### 專屬鑑定封裝卡風格小卡

完成分析後，可將卡牌正面與結果製作成收藏小卡。


### 雙語支援

支援繁體中文與英文切換。


## 使用流程

1. **匯入照片**：選擇同一張卡牌的正面與背面照片。
2. **確認裁切**：裁掉多餘背景，保留卡牌完整四角。
3. **校正外框**：確認自動偵測的四角，手動微調後進行透視校正。
4. **確認內框**：調整建議內框，讓四邊留白落在框外。
5. **檢視報告**：完成正反面操作，查看邊框比例與居中預估級別。
6. **製作小卡**：按下「完成」，替小卡命名，再選擇儲存或分享。
7. **開始下一張**：回到主頁，清除本次資料並重新匯入照片。


## 其他

卡牌的影像校正與邊框偵測在手機端處理，不需要將照片上傳至雲端進行分析。分享圖片時，由使用者選擇接收的應用程式。

CARD ALIGN 依邊框居中比例提供預估，未評估卡角、卡邊磨損與表面狀況，因此結果不代表正式鑑定分數。
